# core/analysis

Derived measurements on a dataset: load summary (peak, flux, ranges, grid step), cross-sections (`section.ts`), contour levels and log-scale helpers (`levels.ts`), contour lines by marching squares (`contours.ts`), the display-only matrix with downsampling (`display.ts`), and cut-off analysis (`cutoff.ts`: gradient scan, sharpness against preset limits, cut-off line trace with a two-segment fit). No DOM code.
